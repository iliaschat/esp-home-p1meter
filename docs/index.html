Reliable & Secure
Smart Meter Reader

ESPHome firmware that reads real-time electricity and gas data from Dutch/Belgian DSMR smart meters via the P1 port — and makes it available to any smart-home platform you prefer.

View on GitHub Easy Install Guide

Works with Home Assistant • Node-RED • Domoticz • MQTT • Custom setups

Why this project?

Existing open-source solutions often crashed, lost Wi-Fi, or sent data unencrypted. This firmware was rewritten from scratch for stability, security and ease of use.

⚡

High-frequency readings

Listens to every DSMR telegram (typically every second) and publishes only when values change.

🔒

Secure by design

Password-protected setup network & web UI, encrypted ESPHome API, and secured OTA updates.

🏠

Platform flexible

Native integration with Home Assistant, Node-RED, Domoticz, or any system that supports MQTT / ESPHome.

🛠️

No-code friendly

Public release can be installed from a browser in minutes — no coding or PlatformIO required.

📶

Robust networking

Recovers cleanly after power loss or network interruptions. Supports DHCP or static IP.

🔄

OTA updates

Update firmware over the air through the web interface or ESPHome’s native OTA mechanism.
